# Zavidoro Corporation - Institutional Website

Sitio web institucional de Zavidoro Corporation, líder en retail deportivo en Paraguay y representante oficial de Nike.

## Tecnologías
- HTML5 Semántico
- CSS3 (Vanilla CSS)
- JavaScript (Vanilla JS)
- Internacionalización (ES/EN)

## Características
- Diseño moderno y premium.
- Soporte multilingüe.
- Información corporativa, tiendas e infraestructura.
- Datos legales accesibles mediante modales.

## Desarrollo
Para visualizar localmente, puedes usar cualquier servidor estático (ej: `http-server`).
